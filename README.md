# Лендинг «2 күндік марафон — Прогрессия»

React 19 + TypeScript + Vite, SCSS Modules, анимации на `motion`.

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/
```

## Настройка

- Ссылка кнопки «Тіркелемін»: `VITE_REGISTER_URL=https://...` в `.env` (по умолчанию `#`).

## Pixel perfect

- Макет — артборд 320px. Все размеры заданы через `u(N)` (`src/styles/_u.scss`) и масштабируются
  пропорционально ширине экрана; на десктопе колонка ограничена 480px.
- Заголовки (Steelfish) и рукописное «не күтеді» (KZ Rosa Marena) — контуры, экспортированные из Figma.
- Основной шрифт макета **TT Firs Neue** коммерческий и в проект не входит: подставлен Golos Text
  (ширина строк совпадает в пределах ~1%). Чтобы получить 100% совпадение, положите лицензионные
  файлы в `public/fonts/` и подключите их через `@font-face` с именем `TT Firs Neue`.
